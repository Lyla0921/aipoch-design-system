# Content Fidelity Rules

## Preserve Supplied Copy

- Do not invent, summarize, paraphrase, or “improve” supplied wording unless explicitly asked.
- Preserve names, dates, numbers, capitalization, punctuation, and terminology.
- When the user supplies replacement copy, delete superseded copy instead of combining versions.
- Do not create missing relationships between people, products, teams, or organizations.
- Do not add claims, metrics, citations, or sources that were not supplied or verified.

## Handling Ambiguity

When content is missing:

1. Search the supplied source files and connected documents.
2. Reuse only exact text that clearly belongs to the requested slide.
3. Leave a clearly marked unresolved item in working files.
4. Ask for the missing source before final delivery.

Never hide uncertainty by generating plausible copy.

## Editing For Fit

Use this order:

1. Improve line breaks.
2. Adjust container width and spacing.
3. Choose a more suitable page archetype.
4. Split the content across slides.
5. Reduce font size only within the documented minimum.

Do not remove meaningful content solely to make a layout fit.

## Bilingual Text

- Keep established product names in their official language.
- Use one translation for repeated technical terms.
- Do not mix capitalization styles within the same component family.
- Keep English system labels compact and secondary to Chinese narrative content.

## Sources

- Put sources near the relevant claim or visual.
- Use one source style throughout the deck.
- Keep source text readable and do not disguise it as decoration.
- Verify URLs and publication names when accuracy matters.
